Project Title: Team Task Manager (Full-Stack)

Description:
This is a full-stack web application that allows users to create projects,
assign tasks, and track progress with role-based access control (Admin/Member).

Features:
- User Authentication (Signup/Login)
- Project and Team Management
- Task Creation and Assignment
- Task Status Tracking (Pending, In Progress, Completed)
- Dashboard with task overview and overdue tracking
- Role-based Access Control (Admin and Member)

Technologies Used:
- Frontend: React.js / HTML / CSS / JavaScript
- Backend: Node.js with Express
- Database: MongoDB / MySQL
- Deployment: Railway

How to Run Locally:
1. Clone the repository from GitHub
2. Install dependencies using npm install
3. Start backend server using npm start
4. Start frontend using npm start
5. Open browser at http://localhost:3000

Deployment:
The application is deployed using Railway and is accessible via the live URL.
